OpenPixelStep
=============

``snowblind.OpenPixelStep``, run with ``strun open_pixel``. Finds open and hot pixels that have appeared since the reference bad-pixel
mask was made, by comparing the calibrated exposures of each detector.
Experimental.
Guide: :doc:`../snowballs_and_flags`.
