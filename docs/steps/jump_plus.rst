JumpPlusStep
============

``snowblind.JumpPlusStep``, run with ``strun jump_plus``. Deprecated, to be removed. Flags the group after each jump and the group
before saturation in readouts that average several frames per group; the
jwst steps now flag what is needed.
Guide: :doc:`../snowballs_and_flags`.
