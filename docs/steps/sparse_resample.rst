SparseResampleStep
==================

``snowblind.SparseResampleStep``, run with ``strun sparse_resample``. The jwst resample step for images with drizzle replaced by spizzle: the
exact variance of each mosaic pixel, and the mosaic's noise factor saved
next to it.
Guide: :doc:`../resampling`.
