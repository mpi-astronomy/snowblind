snowblind
=========

Algorithms for cleaning JWST data: snowball masking, jump and saturation
flag propagation, persistence and open-pixel flagging, 1/f noise removal
along the readout stream, and reset-anchored ramp fitting.  The README of
the repository describes each step and how to run it in the pipeline; the
write-up below holds the measurements behind the two newest steps.
